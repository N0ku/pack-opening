# pack-opening

Design system pour animer l’ouverture d’un **booster de cartes** : on glisse le long du haut du paquet pour le
déchirer, les cartes sortent, on les retourne puis on les fait défiler jusqu’au résumé.

<Canvas of={PackStories.Playground} />

## Principes

| | |
| --- | --- |
| **Une fondation, plusieurs intégrations** | Tout repose sur le custom element `<pack-opening>`. Il marche en HTML pur, et des wrappers typés existent pour React et Vue. |
| **Deux modes** | En `auto`, on passe le booster et les cartes en enfants et la structure est générée. En `headless`, on écrit soi-même chaque part (`data-part="…"`). |
| **Logique / style / HTML séparés** | Le TypeScript n’écrit que des attributs d’état (`data-state`, `data-phase`…) et des variables CSS. Toute l’animation est en CSS. |
| **Style en couches** | `tokens.css` (DTCG), `base.css` (mécanique obligatoire) et `theme.css` (visuel optionnel), dans `@layer po.tokens, po.base, po.theme` : vos styles l’emportent toujours. |
| **Features à la carte** | Un preset (`full`, `minimal`, `none`), puis `enable` / `disable` en HTML, ou `features: { … }` en JS. |
| **Accessible par défaut** | Bouton natif, clavier complet, focus géré, annonces aux lecteurs d’écran, cartes non révélées cachées, `prefers-reduced-motion`. |
