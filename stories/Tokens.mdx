# Tokens

Source unique : les fichiers **DTCG** de `tokens/`, en trois couches, construits par Style Dictionary
(`npm run tokens`) en `tokens.css` (variables `--po-*`) et en objets JS/TS.

| Couche | Fichiers | Rôle |
| --- | --- | --- |
| core | `tokens/core/*.tokens.json` | Palette, durées, courbes, tailles. Valeurs brutes. |
| semantic | `tokens/semantic/{light,dark}.tokens.json` | Intentions (texte, focus, lueur, rareté), par thème. |
| component | `tokens/component/pack-opening.tokens.json` | Ce que le composant consomme. C'est la couche à surcharger. |

Le thème sombre s’active avec `data-theme="dark"` ou automatiquement avec `prefers-color-scheme: dark`.
Pour personnaliser, surchargez les tokens **component** :

```css
pack-opening {
  --po-pack-width: 320px;
  --po-cut-glow: hotpink;
  --po-tear-line: 0.12;
}
```
